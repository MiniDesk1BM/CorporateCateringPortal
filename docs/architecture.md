# Architecture cible

## Objectif
Mettre en place une plateforme vitrine institutionnelle pour une entreprise de restauration collective et de services.

## Stack
- **Angular** pour le frontend
- **.NET 10** pour une future API REST
- **Azure** pour l’hébergement, CI/CD et observabilité

## Cible Azure
- **Azure Static Web Apps** ou hébergement frontend dédié
- **Azure App Service** pour l’API .NET
- **Azure SQL** ou autre stockage à définir ultérieurement
- **Application Insights** pour le monitoring

## Découpage fonctionnel initial
- Accueil
- Nos services
- Secteurs desservis
- Engagements RSE
- Actualités
- Contact

## Phase actuelle
Prototype statique avec données bouchon pour validation UX/UI et structure projet.
