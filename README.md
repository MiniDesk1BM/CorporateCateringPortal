# CorporateCateringPortal

Site web statique pour une multinationale française spécialisée dans la restauration collective et les services aux entreprises et aux collectivités.

## Stack cible
- **Frontend**: Angular
- **Backend/API (plus tard)**: .NET 10
- **Cloud cible**: Azure
- **Base de données**: à implémenter plus tard

## État actuel
Ce dépôt contient une **maquette statique** avec données bouchon, structurée pour préparer une future séparation :
- `frontend/` : application Angular (structure de démarrage statique)
- `backend/` : squelette .NET 10 pour future API
- `docs/` : notes d’architecture

## Données
Les contenus affichés sont des **données bouchon** dans des fichiers TypeScript/JSON.

## Évolutions prévues
- Connexion à une API .NET 10
- Intégration base de données
- Déploiement sur Azure App Service / Static Web Apps
- Authentification et espace client
